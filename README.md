# 오후세시 책방

오후 3시에 문을 여는 가상의 독립서점 랜딩 페이지 (HTML/CSS 연습 프로젝트)

## 폴더 구조

```
ohusesi-bookshop/
├─ index.html
├─ styles/
│  ├─ reset.css       # 기본 스타일 리셋
│  ├─ variables.css   # 컬러·폰트·간격 변수
│  └─ style.css       # 컴포넌트 스타일 (CSS 네스팅)
├─ scripts/
│  └─ main.js         # 책 이름 → 유튜브 플레이리스트 추천
└─ README.md
```
